# 🤝 Guía de Contribución a BioShield-AI

¡Gracias por tu interés en fortalecer la bioseguridad global! **BioShield-AI** es un proyecto abierto a la colaboración de universidades, ONGs y desarrolladores independientes.

## 🏛️ Colaboración Académica e Institucional
Buscamos socios que deseen integrar:
- **Modelos de Dispersión:** Nuevos algoritmos de fluidos o predicción de patógenos.
- **Validación de Datos:** ONGs que operen sensores en terreno.
- **Seguridad Criptográfica:** Mejoras en el protocolo de auditoría blockchain.

## 🛠️ Proceso de Desarrollo

### 1. Reportar Errores o Sugerencias
Si encuentras un fallo o tienes una idea, abre una **Issue** describiendo el problema y los pasos para reproducirlo.

### 2. Flujo de Trabajo (Git Flow)
1. Realiza un **Fork** del proyecto.
2. Crea una rama para tu mejora: `git checkout -b feature/mejora-algoritmo`.
3. Asegúrate de que tu código pase el **Profiling de Recursos** (`@profile_resources`).
4. Realiza un **Pull Request (PR)** detallando los cambios.

## 🌿 Estándares de Código y Sostenibilidad
Para mantener nuestro enfoque de **Ingeniería Verde**, toda nueva funcionalidad debe:
- **Ser Eficiente:** Evitar algoritmos de complejidad $O(n^2)$ o superior si existen alternativas optimizadas.
- **Estar Documentada:** Usar comentarios claros y actualizar el `README.md` si es necesario.
- **Pasar Auditoría:** No comprometer la estructura de la clase `BioShieldChain`.

## 📜 Código de Conducta
Promovemos un ambiente de respeto y colaboración científica. Al participar, te comprometes a mantener altos estándares de integridad de datos.
